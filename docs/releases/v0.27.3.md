# Vittics Builder 0.27.3 — a small project gets a small stack

A one-page checklist rebuilt on 0.27.2 still used 14.8M input tokens: the plan added Vitest, Playwright and a Node
server to a static page, the e2e ticket alone took about 3.4M, and a ticket was sent back twice because nobody had
clicked through the app in a browser.

## What changed

- **Small projects get a minimal stack:** no packages, no test framework, no browser automation, no build step; the
  built-in test runner, one build ticket, no separate end-to-end ticket.
- **Small projects skip the design prototype**; the design stays about one page.
- **A ticket blocked only by checks a person has to do passes** with a note carried to the release check, instead of
  being sent back for rework. Real defects are still sent back.

## Install

- **macOS (Apple Silicon):** Quit Vittics Builder, open the DMG, and drag the app into Applications. Choose Replace if
  prompted. If macOS cannot verify it, use System Settings → Privacy & Security → Open Anyway.
- **Windows (x64):** Quit Vittics Builder and run the setup installer.

Existing company data is kept.

## Limits

Agents still start from scratch on every run (no session resume). The saving is an estimate until the same project is
rebuilt on this version. Desktop installers are unsigned.
