# Vittics Builder 0.27.2 — fairer reviews, no runaway agents, automatic restart after a limit

The checklist pilot finished on 0.27.1 at 18.8M input tokens (90% re-read from cache): builders 60%, QA and reviews
25%. It also put two reviewers on probation for blocking on checks only a person could do.

## What changed

- **Reviewers are not marked wrong** for a block that only asked for evidence a person has to give, when the CTO
  accepts anyway.
- **Quitting the app stops its agents**, and a backend with no parent exits by itself.
- **Work restarts after a usage limit** at the time the engine gives (or 30 minutes), up to four times in a row, while
  Vittics is open. An expired login still waits for you.
- **Small-project builders are told to work economically.**
- One shared process-liveness check.

## Install

- **macOS (Apple Silicon):** Quit Vittics Builder, open the DMG, and drag the app into Applications. Choose Replace if
  prompted. If macOS cannot verify it, use System Settings → Privacy & Security → Open Anyway.
- **Windows (x64):** Quit Vittics Builder and run the setup installer.

Existing company data is kept; a new column is added automatically.

## Limits

Agents still start from scratch on every run (no session resume), there are no desktop notifications, failover is off
by default, and the token savings are not yet confirmed on a clean run. Desktop installers are unsigned.
