# Vittics Builder 0.23.0 — small projects, faster releases

In a pilot, a one-page tip calculator took 4½ days, 25 tickets and 102 agent runs, while the agents only
worked for 3.2 hours. This release removes most of that waiting.

- **Small projects.** Choose **Size: Small** on Home (or in New idea, or `--size small`) for something like a
  calculator, a form or a single page. It skips the idea assessment, keeps the requirements to at most 8
  acceptance criteria, has one reviewer per ticket, goes to the CTO after one repair attempt, and has no
  audits. Release QA and the acceptance checks still run. **Standard** is unchanged and stays the default.
- **Release checks no longer restart over small tickets.** While they run, tickets the team files wait in the
  backlog (an urgent or high-priority bug is still built first), and the release review lists them for you.
- **Audits without a verdict** are retried once, then shown at the release review instead of becoming fix
  tickets with no findings. Autopilot does not approve a release past them.
- **Agents finish what they start.** Claude Code's background tasks are turned off for agents, and every agent
  is told to run commands in the foreground. An agent that started a long job in the background ended its
  run without a verdict.
- **Description text in `product.json` can change** without a new CTO approval; only its name, checks and
  start command are compared.
- **Pause and Resume** a project from its page (`vittics-builder pause 3`). **Resume work** now says what
  happened: started, already working, or which decision it is waiting for.
- **Your computer stays awake** while Vittics Builder runs, so overnight work is not frozen
  (`machine.keep_awake` in `org.yaml`).

## Install

- **macOS (Apple Silicon):** Quit Vittics Builder, open the DMG, and drag the app into Applications. Choose
  Replace if prompted. If macOS cannot verify it, use System Settings → Privacy & Security → Open Anyway.
- **Windows (x64):** Quit Vittics Builder and run the setup installer.

Existing company data is kept, and existing projects stay Standard. Click **Resume work** on your projects
after reopening Vittics Builder.

The source tests (323) passed locally on macOS; CI runs them on macOS, Windows and Linux, and the installer
builds smoke-test the bundled backend.
