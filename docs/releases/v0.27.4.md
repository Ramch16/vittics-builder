# Vittics Builder 0.27.4 — a small project builds only its plan

Rebuilding the one-page checklist on 0.27.3 cut planning and build cost, then stopped at review: the code reviewer filed
a "Manually verify browser flow" ticket, the only QA agent did it, and no independent QA existed to review it.

## What changed

- **A small project builds only its plan.** Tickets agents file themselves wait in the backlog for triage; an urgent or
  high bug is still built.
- **A small project is not stopped by a missing second QA.** The code reviewer's check stands; it still stops if nobody
  at all could review.

## Install

- **macOS (Apple Silicon):** Quit Vittics Builder, open the DMG, and drag the app into Applications. Choose Replace if
  prompted. If macOS cannot verify it, use System Settings → Privacy & Security → Open Anyway.
- **Windows (x64):** Quit Vittics Builder and run the setup installer.

Existing company data is kept.

## Limits

Agents still start from scratch on every run (no session resume). Desktop installers are unsigned.
